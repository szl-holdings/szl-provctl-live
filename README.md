# szl-provctl-live

**Provenance-DAG verify hologram.** A static, self-contained page that renders a **real**
provenance DAG produced by the canonical [`SZLHOLDINGS/szl-provctl`](https://huggingface.co/SZLHOLDINGS/szl-provctl)
governed kernel — an [in-toto Statement v1](https://in-toto.io/Statement/v1) + [SLSA provenance v1](https://slsa.dev/provenance/v1)
run — and **re-verifies every SHA3-256 receipt digest in _your_ browser**, edge by edge.

- **Live Space:** https://huggingface.co/spaces/SZLHOLDINGS/szl-provctl-live
- **Suite hub:** https://huggingface.co/spaces/SZLHOLDINGS/szl-kernels-live
- **Status:** ROADMAP → **LIVE** (static page live; the sample DAG is generated by the real kernel, re-hashed client-side).

## What it does

The lane the supply-chain leaders leave open: Sigstore/SLSA/in-toto define the *formats*, but
no tool walks an **ML provenance DAG and verifies every edge**. `szl-provctl` does — and this page
lets anyone re-run that verification with nothing but a browser:

| Panel | Source | Label |
|---|---|---|
| Provenance DAG (3 nodes: `train → finetune → eval`) | generated by canonical `szl_provctl` kernel | **REPORTED** (kernel-emitted) |
| Per-receipt SHA3-256 hash-chain | re-hashed with vendored, pinned [js-sha3 0.8.0 (MIT)](https://github.com/emn178/js-sha3) | **MEASURED-in-your-browser** |
| in-toto v1 Statement (subject digest = chain head) | kernel `statement_from_chain()` | **REPORTED** |
| SLSA provenance v1 statement | kernel `slsa_statement()` | **REPORTED** |
| honest-BLOCKED `eval` node | surfaced in the DAG, **never dropped** | **REPORTED** |

A **Tamper** button mutates a real receipt without re-hashing so you can watch the in-browser
verification catch the break — proving the check is real, not decorative.

## Honesty doctrine (binding)

- **MEASURED-in-your-browser** = this browser re-computed the SHA3-256 digest and it matched ·
  **REPORTED** = as emitted by the kernel — never fabricated.
- The digest is an **integrity** fingerprint (tamper-evidence + ordering), **not** a signature
  and **not** proof of authorship.
- **Λ = Conjecture 1** — advisory, never proven; `proven_trust` structurally locked `False`.
- **Energy MEASURED-only** — `None` here (no NVML), never an invented joule.
- **honest-BLOCKED** nodes are surfaced in the DAG, never silently dropped.
- **0 runtime CDN** — js-sha3 is vendored inline and pinned.
